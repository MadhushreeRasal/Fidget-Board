# Fidget Board

An interactive frontend mini project built using **HTML** and **CSS**, inspired by the idea of a virtual fidget board for playful user interaction.

This project explores various **CSS transforms**, **transitions**, hover interactions, 2D/3D effects, grid layouts, and responsive design concepts in a fun and creative way.

**Live Demo:**
[https://madhushreerasal.github.io/Fidget-Board/](https://madhushreerasal.github.io/Fidget-Board/)

# Features

* Interactive hover-based UI effects
* CSS transforms including:

  * Translate
  * Rotate
  * Scale
  * Skew
  * 3D RotateX / RotateY
* Smooth CSS transitions
* Responsive layout using media queries
* Grid-based page structure
* Playful “fidget board” themed interface

# Technologies Used

* HTML5
* CSS3

# Concepts Practiced

This project was created to practice and experiment with:

* CSS transitions
* 2D transformations
* 3D transformations
* Hover interactions
* CSS Grid
* Responsive web design
* Basic UI interaction design

# Responsive Design

The project includes responsive adjustments for smaller screen sizes using media queries. The layout adapts differently for tablets and mobile devices while preserving the interactive feel of the project.

# Project Goal

This project was designed around a playful concept where the interactions feel natural and intentional — similar to digital fidget toys users can interact with when bored.
